# 灰岭之夜 Grizzly Ridge — 项目介绍

> Ship It Sunday with Hi3D · 2026-11-08 · 游戏赛道
> 线上试玩：https://pengyuchen2025-ship-it.github.io/grizzly-ridge/ （手机扫码即玩，无需安装）
> 代码仓库：https://github.com/pengyuchen2025-ship-it/grizzly-ridge

## 一句话介绍
病毒爆发之夜，你就是那只怪物：在雨夜的破旧美式小城"灰岭市"里，操控一团由许多人体融合而成的肉块怪物，滚动、吞噬、爬楼、跳跃，压爆警车、撞落直升机，看你能撑多久。

## 玩法
| 动作 | 操作（电脑 / 手机） | 说明 |
|---|---|---|
| 滚动吞噬 | WASD 或方向键 / 屏幕上拖动 | 碰到路人就把他拽进体内：血液飞溅、地上留下血迹，怪物变大、回血，身上长出被吃者的手或腿 |
| 跳跃砸地 | 空格 / 右下角按钮 | 起跳和落地都会砸裂地面、掀起冲击波；从高处落下会震倒周围的人、震起车辆 |
| 爬墙上楼 | 贴着墙继续推 | 爬墙时窗户一扇扇碎裂；楼顶有挥手求救的幸存者 |
| 压爆车辆 | 体积够大后撞上去 | 车辆翻飞、爆炸、起火，并可引发连环爆炸；体积不够时可以先爬上车顶 |
| 击落直升机 | 从楼顶跳起来撞 | 直升机坠毁时引发大爆炸 |

**警力随时间升级**：平静 → 报警（警察开枪）→ 新闻直升机（低空悬停救人，最好撞）→ 警车出动 → 警用直升机俯冲扫射 → 全城戒严（路口设警车路障）→ 末日。
**结束**：血量归零后进入"突发新闻"风格的结算页，显示存活时间、吞噬人数、压爆车辆、击落直升机、最终体积、得分和威胁评级（街头怪谈 → 午夜惊魂 → 城市噩梦 → 灰岭末日 → 天灾级生物），并记录本机最高分。

**城市里的其他互动**：商业街的加油站一撞就会三连爆；消防栓被撞会喷出水柱；街上有行驶的车辆，看到怪物会逃跑；东北角是着火冒烟的废墟。

## Hi3D 的使用
游戏里的 **8 个角色和载具都由 Hi3D 生成**：怪物（重做过一次，最终版是"中心人形 + 四周伸出的手脚"）、男路人、女路人、警察、警车、汽车、直升机。

制作流程：
1. **统一风格**：所有物件都用同一句风格描述词（low-poly 卡通风格、单个物体、纯色背景、45 度视角、光照均匀）生成图片，保证画风统一。
2. **Hi3D 图生 3D**：在 Hi3D 网页端把图片转成 3D 模型，导出 GLB。
3. **压缩**：原始模型单个约 14 万个面、4 MB。用 gltf-transform 减面、压缩贴图，降到 2 千到 1.1 万个面、36–230 KB，7 个模型总共从约 28 MB 降到约 1.2 MB，手机也能流畅运行。
4. **自动接入**：游戏读取模型清单，按配置的身高、车长等尺寸自动缩放和摆正。没有模型的东西会用代码画的占位模型代替，不影响运行。

## 用代码生成的部分
- **整座城市**：分区生成，包括市中心玻璃高楼（带退台和停机坪）、霓虹商业街（底商、条纹雨棚、招牌、加油站）、红砖住宅区（消防梯、水塔）、着火的废墟；湿路面和水洼、人行道、斑马线、路灯光斑、红绿灯、远景城市剪影、天空渐变、烟柱。
- **特效**：爆炸、火焰、血液、碎玻璃、地面裂纹和冲击波、雨、警灯、探照灯。
- **怪物身上长出的手脚**：随吞噬数量增加，不停挣扎摆动。
- **界面**：紧急广播风格的开始页（带加载进度条）、突发新闻风格的结算页、血条和体积条等 HUD。

## 技术
- **纯 HTML + JavaScript + Three.js（r170）**，无构建步骤，部署在 GitHub Pages，打开网址即玩。
- 画面：Bloom 辉光后期、可调像素化（按 P 切换）、挡住视线的楼自动变透明；帧率低于 28 时自动降低画质。
- 声音：40 多个 CC0 / 免版税真实录音音效（OpenGameArt、BigSoundBank），警笛和直升机声随距离变化；背景音乐由作者提供。
- 碰撞：每栋楼是一个包围盒，用来实现爬墙、站上楼顶、楼间跳跃。

## 代码结构
| 文件 | 内容 |
|---|---|
| `index.html` | 页面、HUD、开始页、结算页、样式 |
| `src/config.js` | 所有可调数值：成长速度、伤害、警力波次、模型尺寸 |
| `src/main.js` | 游戏逻辑：模型加载、怪物、路人、警察、车辆、直升机、特效、音效、镜头 |
| `src/city.js` | 程序化城市生成 |
| `assets/models/` | Hi3D 模型（压缩后的 GLB）和清单 |
| `assets/sfx/`、`assets/audio/` | 音效和背景音乐 |
| `tools/compress_models.sh` | Hi3D 模型压缩脚本 |
| `tools/bump_version.sh` | 发布前更新版本号，避免浏览器缓存旧代码 |

本地运行：在项目文件夹里执行 `python3 -m http.server 8000`，然后浏览器打开 http://localhost:8000 。
