# 灰岭之夜 Grizzly Ridge

病毒爆发之夜，你是那只怪物。Three.js 网页游戏，模型由 Hi3D 生成。

- 本地运行：`python3 -m http.server` 后打开 http://localhost:8000
- 模型：GLB 放进 `assets/models/`，并把 id 写进 `assets/models/manifest.json`

## 音效与音乐来源
- 音效（`assets/sfx/`）均为 **CC0 / 免版税** 素材，已裁剪和转码：
  - OpenGameArt（CC0）：80 CC0 creature SFX、CC0 Deep Monster Roar、8 Wet Squish Slurp Impacts、Female Scream 1、Female High-Pitched Scream SFX、Sirens and Alarm Noise
  - Additional sounds: Joseph SARDIN - [BigSoundBank.com](https://bigsoundbank.com)（直升机、爆炸、碎玻璃、枪声、骨头碎裂、雨声）
- 背景音乐（`assets/audio/bgm.mp3`）由作者提供。
